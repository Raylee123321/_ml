# F1 AI 遙測影片同步分析網頁平台 (Web Dashboard)

本子專案建立了一個高度互動的 Web 儀表板，將真實/模擬的兩位車手遙測數據（速度、油門、煞車）與車手的單圈 Onboard 錄影（影片）進行實時同步。

您可以一邊觀看車手在 Monaco 或 Spa 的 Onboard 影片，一邊即時查看兩人在同一個賽道位置的煞車踩踏程度與速度差。點擊右側的 **AI 診斷卡片**，影片還會自動跳轉至該失誤彎道的前 2.5 秒，讓您能仔細端詳車手的入出彎動態！

---

## 核心互動功能

1. **影片-遙測二分搜尋同步 (PlayTime-to-Distance Sync)**：
   監聽影片的播放進度，即時將影片播放時間（Time）與遙測距離（Distance）對齊。油門與煞車指示條、速度數位儀表將會隨著賽車前進即時跳動。
2. **Chart.js 互動游標與背景高亮**：
   圖表中會隨影片播放平滑移動一條紅色的垂直引導線。此外，AI 檢測到的「瓶頸區段」會在圖表背景以紅色（損失時間）或綠色（優勢區段）透明區塊高亮標示。
3. **AI 瓶頸診斷面板**：
   列出所有模型偵測出的行為瓶頸，並計算具體數值（如：晚煞車秒數、出彎速度損失）。
4. **一鍵跳轉觀看**：
   點擊 AI 卡片，影片直接跳轉至該關鍵事件點。
5. **本地影片拖放載入**：
   您可以將任何 Monaco 站的 `.mp4` 單圈 onboard 錄影直接拖曳進網頁中，網頁便會自動與遙測對齊。您也可以使用「影片延遲修正」微調影片起點，實現 100% 完美同步！

## 啟動與使用步驟

### 1. 生成最新遙測數據 (JSON)
確保你已經在專案根目錄下訓練好模型，然後執行導出腳本：
```bash
# 確保你在 e:/co/_ml/mid 目錄下
python export_web_data.py
```
此步驟會在 `web/` 目錄下生成 `telemetry_data.json`。

### 2. 啟動本地伺服器
由於網頁需要載入本地的 JSON 檔案，瀏覽器出於安全限制 (CORS 政策) 不允許直接雙擊打開 `.html` 檔案讀取 JSON。您需要啟動一個簡單的本地伺服器：

在終端機中切換到 `web` 目錄，然後執行：
```bash
# 使用 Python 內建的超輕量 Web Server
python -m http.server 8000
```

### 3. 體驗與分析
1. 打開瀏覽器並訪問：`http://localhost:8000`
2. 網頁預設會加載一段賽車練習單圈的開源 onboard 視訊以展示同步效果。
3. **上傳你自己的 Monaco onboard 錄影**：
   * 為了對比 2026 Monaco GP 的 ANT vs VER，你可以將對應的 Q3 onboard 錄影（`.mp4` 格式）直接**拖曳**到影片播放器區域，或點擊「更換 Onboard 影片」按鈕上傳。
   * 如果影片與遙測沒有完全對齊，在「影片延遲修正」欄位中輸入微調值（例如 `1.5` 秒或 `-0.8` 秒），直到賽車踩煞車的瞬間，儀表板的 `Brake` 紅色條剛好衝高為止。
   * 點擊右側的 **AI 卡片**，影片將自動精準跳轉至該失誤彎道，助你分析行為瓶頸！
